## Local wrapper corrections

`scripts/prepare-runtime.mjs` copies the exact pinned npm files into the ignored `vendor/` directory, then makes documented corrections to its JavaScript adapter: permutation replies omit a spurious length byte; sum-selection prompts decode mandatory cards before optional cards and include complete locations; Set-card shuffle messages decode their byte count and separate source/destination arrays; movement messages retain the trailing reason bitmask so the log can distinguish costs, effects, battle destruction and materials. TYPE queries consume their payload rather than desynchronizing following fields; counter queries decode the low uint16 as the type and the high uint16 as the amount, matching pinned core `card.cpp` QUERY_COUNTERS; monster ATK/DEF queries decode signed int32 values so unknown stats do not become unsigned billions. The synchronous runtime releases callback closures when a duel is destroyed and on failed creation, and restores its temporary stack on both success and failure. No WebAssembly binary is modified; Lua corrections are listed separately below. The script checks each source pattern before patching, and regression tests exercise these paths. The field adapter queries the corrected TYPE, race, attribute and Level fields for live card metadata.

## Rebuild and inspect

The complete application adapter and local patches are in this repository. `npm ci && npm test && npm run build` reconstructs the distributed JavaScript/WASM files from the pinned npm dependency, tests them, and includes the complete licenses, source links, original Lua sources, and manifest in the static output and offline shell. To rebuild the underlying WASM rather than use the npm binary, clone the pinned wrapper source with its recorded submodules and follow its Emscripten build instructions.

Local correction: `overrides/c88132637.lua` rechecks Twin-Headed Wolf’s live controller and supporting Fiend before applying negation, and emits a card hint for attribution. It is included in the bundled script pack and retained by `scripts/update-rules.py`.

Local correction: `overrides/c16768387.lua` uses Big Eye’s chosen amount (`ac`) when sorting the top of the Deck, instead of always using its maximum (`ct`). It is included in the bundled pack and retained by `scripts/update-rules.py`. Saved matches without rules version 2 use the original operation during verified replay.
